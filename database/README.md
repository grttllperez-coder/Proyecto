# Base de datos Plaza Tezontle

Archivo: `plaza_tezontle_100.sql`

Compatible con **PostgreSQL / pgAdmin 4**.

## Distribución de los 100 registros

- 25 tiendas
- 20 promociones
- 20 locales comerciales
- 15 restaurantes
- 20 servicios
- **Total: 100 registros**

## Cómo cargarla en pgAdmin

1. Crea o selecciona una base de datos PostgreSQL.
2. Abre **Query Tool**.
3. Abre `plaza_tezontle_100.sql`.
4. Ejecuta todo el script.
5. Al final se ejecuta una consulta que muestra la cantidad de registros por tabla y el total.
